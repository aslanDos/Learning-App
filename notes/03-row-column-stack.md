# 03. Row, Column и Stack

Ветка: `lesson/03-row-column-stack`. Пример: [`lib/main.dart`](../lib/main.dart).
Предыдущая тема: [Constraints](02-constraints.md).

## Как выбрать виджет

| Задача | Виджет | Пример интерфейса |
| --- | --- | --- |
| Разместить детей горизонтально | `Row` | Иконка и подпись рядом |
| Разместить детей вертикально | `Column` | Заголовок, описание, кнопка |
| Наложить детей друг на друга | `Stack` | Изображение с бейджем |

Все три виджета принимают список `children`. Их можно вкладывать друг в друга:
например, несколько `Row` внутри `Column`.

## Row и Column: две оси

| Виджет | Главная ось (main axis) | Поперечная ось (cross axis) |
| --- | --- | --- |
| `Row` | Горизонтальная | Вертикальная |
| `Column` | Вертикальная | Горизонтальная |

`mainAxisAlignment` распределяет детей вдоль главной оси:

- `start` — собирает их у начала;
- `center` — собирает группу по центру;
- `end` — собирает у конца;
- `spaceBetween` — делит свободное место между детьми, без промежутков по краям;
- `spaceAround` — добавляет пространство вокруг каждого ребёнка; крайние промежутки вдвое меньше внутренних;
- `spaceEvenly` — делает все промежутки, включая крайние, одинаковыми.

Распределяется именно свободное место: если его нет, дополнительные промежутки не появятся.

`crossAxisAlignment` задаёт выравнивание поперёк главной оси:

- `start`, `center`, `end` — у начала, по центру или у конца;
- `stretch` — растягивает детей по поперечной оси в пределах доступного размера;
- `baseline` — выравнивает по текстовой базовой линии; нужно также задать `textBaseline`.

У Row по умолчанию `mainAxisAlignment: start`, `crossAxisAlignment: center`.
У Column те же значения, но направления осей другие.

### Начало и конец зависят от направления

В приложении используется направление текста слева направо (LTR): начало Row — слева,
начало горизонтальной поперечной оси Column — тоже слева. В RTL эти стороны меняются.
Вертикальное направление по умолчанию идёт сверху вниз; его можно изменить через `verticalDirection`.

## Пример Row

```dart
SizedBox(
  width: 240,
  height: 120,
  child: Row(
    mainAxisAlignment: MainAxisAlignment.spaceBetween,
    crossAxisAlignment: CrossAxisAlignment.center,
    children: [
      Icon(Icons.home, size: 32),
      Text('Главная'),
      Icon(Icons.chevron_right, size: 24),
    ],
  ),
)
```

Свободное горизонтальное место делится между тремя детьми.
Их центры по вертикали совпадают. Если заменить Row на Column, те же параметры
будут распределять детей по вертикали и центрировать по горизонтали.

## mainAxisSize: размер самой группы

`mainAxisSize` отвечает за размер Row или Column вдоль главной оси:

- `MainAxisSize.max` — значение по умолчанию; при конечном максимуме стремится занять его;
- `MainAxisSize.min` — стремится занять место по размеру содержимого.

Оба варианта учитывают ограничения родителя. Если родитель требует ровно 240,
`mainAxisSize: min` не сможет уменьшить размер до 100.
В приложении область 240 × 240 задана точно, поэтому для сравнения `mainAxisSize`
нужно сначала ослабить внешние ограничения, например через Center.

## Stack: размещение слоями

Дети рисуются по порядку списка: первый внизу, последний сверху.
В нашем примере блок C всегда последний. Переключатель меняет местами только A и B.

`alignment` выравнивает детей без заданной позиции:

```dart
SizedBox(
  width: 240,
  height: 240,
  child: Stack(
    alignment: Alignment.center,
    children: [
      SizedBox(width: 120, height: 120,
        child: ColoredBox(color: Colors.blue)),
      SizedBox(width: 60, height: 60,
        child: ColoredBox(color: Colors.green)),
    ],
  ),
)
```

Зелёный блок находится по центру поверх синего.
Чтобы разместить ребёнка у конкретного края Stack, используй `Positioned`:

```dart
Positioned(
  top: 16,
  right: 16,
  child: Icon(Icons.favorite),
)
```

Здесь позиция определяется относительно Stack, а не экрана.
`Positioned` должен находиться внутри Stack; не оборачивай его снаружи в Padding.
Если нужен отступ внутри позиционированного элемента, помести Padding в `Positioned.child`.

Если задать `left` и `right`, ширина определяется оставшимся пространством.
Аналогично `top` и `bottom` задают высоту. Нельзя одновременно задавать
`left`, `right` и `width` или `top`, `bottom` и `height`.

Размер самого Stack зависит от внешних ограничений и детей без Positioned.
Позиционированные дети не увеличивают его размер. В приложении размер явно задан как 240 × 240.

## Частые ошибки

- Путать оси: у Column `mainAxisAlignment` управляет вертикалью.
- Ожидать переноса у Row: он не переносит детей на следующую строку. Для переноса есть Wrap.
- Ожидать прокрутки у Column: он сам не прокручивается.
- Добавлять детей, которые не помещаются: Row и Column могут показать overflow.
- Считать, что `spaceBetween` создаёт место при нехватке пространства: оно лишь распределяет остаток.
- Ожидать, что `Stack.alignment` переместит ребёнка с явно заданными `top` и `right`.

Как делить доступное пространство через Expanded, Flexible и Spacer, разберём в следующей теме — Flex.

## Практика

1. В Row выбери `spaceBetween`. Затем переключись на Column. Объясни направление промежутков.
2. В Column выбери `crossAxisAlignment: end`. Какой край блоков совпал?
3. В Stack поменяй местами слои A и B. Почему C остался сверху?
4. Включи Positioned для C и меняй alignment. Какие блоки перемещаются?
5. В коде замени `right: 16` на `left: 16`. Предскажи положение C перед запуском.
6. Собери Row с иконкой и Column из двух Text — получится основа строки профиля.

Для повторения: Row и Column выстраивают детей вдоль оси, Stack размещает их слоями.
Во всех случаях действуют ограничения родителя.
