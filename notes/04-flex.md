# 04. Flex, Expanded, Flexible и Spacer

Ветка: `lesson/04-flex`. Пример: [`lib/main.dart`](../lib/main.dart).
Предыдущий урок: [Row, Column и Stack](03-row-column-stack.md).

## Что такое Flex

`Flex` располагает детей вдоль выбранной главной оси:

```dart
Flex(
  direction: Axis.horizontal,
  children: [Text('A'), Text('B')],
)
```

`Row` — специализация Flex для горизонтального направления, `Column` — для вертикального.
У них действуют знакомые `mainAxisAlignment`, `crossAxisAlignment` и `mainAxisSize`.
Flex сам по себе не делает всех детей гибкими: для участия в распределении места
нужны `Expanded`, `Flexible` или `Spacer`.

## Как распределяется место

В нашем примере главная ось имеет длину 240:

1. Сначала измеряется обычный ребёнок A. Он занимает 48.
2. Остаётся `240 − 48 = 192`.
3. Остаток делится между flex-детьми пропорционально их коэффициентам.
4. Каждый из них получает ограничения согласно своему `fit`.
5. После выбора размеров детей оставшееся незанятое место может распределить `mainAxisAlignment`.

При `flex: 1` у B и `flex: 2` у C сумма коэффициентов — 3:

```text
Доля B = 192 × 1 / 3 = 64
Доля C = 192 × 2 / 3 = 128
```

`flex` — вес при делении остатка, а не число пикселей и не доля всего экрана.
В приложении коэффициент C можно менять от 1 до 3.

## Expanded: заполнить всю долю

```dart
Row(
  children: [
    SizedBox(width: 48, child: Text('A')),
    Expanded(flex: 1, child: Text('B')),
    Expanded(flex: 2, child: Text('C')),
  ],
)
```

Если ширина Row равна 240, B получает ровно 64, C — ровно 128.
Внутренний запрос меньшей ширины не отменяет этих ограничений.
По поперечной оси Expanded сам по себе ребёнка не растягивает.

`Expanded` соответствует `Flexible(fit: FlexFit.tight)`.

## Flexible: можно занять меньше доли

У `Flexible` по умолчанию `fit: FlexFit.loose`.

```dart
Flexible(
  flex: 1,
  child: SizedBox(
    width: 40,
    height: 40,
    child: ColoredBox(color: Colors.red),
  ),
)
```

В нашем горизонтальном примере для B выделено до 64, но он запрашивает 40.
Итоговая ширина B — 40. C продолжает занимать свою долю 128.
Оставшиеся `64 − 40 = 24` не передаются C повторно.
При `mainAxisAlignment: start` они остаются в конце ряда.

Flexible разрешает меньший размер, но не гарантирует его: ребёнок, который
стремится заполнить доступное место, может занять весь разрешённый максимум.

## Spacer: гибкий пустой промежуток

```dart
Row(
  children: [
    Text('Начало'),
    Spacer(flex: 1),
    Text('Середина'),
    Spacer(flex: 2),
    Text('Конец'),
  ],
)
```

Spacer участвует в том же распределении места, но создаёт пустоту вместо содержимого.
Второй промежуток получает вдвое больше первого, если они имеют коэффициенты 1 и 2.
Если одновременно есть Expanded и Spacer, они делят общий остаток вместе.

В приложении в режиме Spacer блоки A, B и C фиксированы: 48, 40 и 48.
На промежутки остаётся `240 − 48 − 40 − 48 = 104`.

Spacer заполняет свою долю. Поэтому, когда всё свободное место уже занято
Spacer и другими tight flex-детьми, `mainAxisAlignment: spaceBetween`
не создаёт дополнительных промежутков.

## Сравнение

| Виджет | Что получает долю | Должен заполнить её? |
| --- | --- | --- |
| Expanded | Ребёнок | Да |
| Flexible с loose | Ребёнок | Нет |
| Spacer | Пустой промежуток | Да |
| SizedBox без flex-обёртки | Размер по обычным правилам layout | В распределении flex не участвует |

## Важное правило дерева

Пиши так:

```dart
Row(
  children: [
    Expanded(
      child: Padding(
        padding: EdgeInsets.all(8),
        child: Text('Текст'),
      ),
    ),
  ],
)
```

`Padding(child: Expanded(...))` непосредственно внутри Row — неправильный порядок.
Между Expanded/Flexible и их Flex-родителем не должно быть виджетов,
создающих промежуточный render object, например Padding или SizedBox.
Обычная обёртка StatelessWidget/StatefulWidget допустима, если внутри она не нарушает это правило.

## Ограниченная главная ось

Чтобы заполнить оставшееся место, нужно знать его конечный размер.
Типичная ошибка — Expanded внутри Column, расположенной в вертикальном SingleChildScrollView:
прокрутка допускает неограниченную высоту, поэтому вычислить конечный остаток нельзя.

В нашем приложении Flex помещён в SizedBox 240 × 240: обе оси ограничены.
Это позволяет безопасно переключать направление даже внутри списка урока.
В теме Scrolling отдельно разберём, как строить прокручиваемые экраны.

## Практика

1. В Expanded выставь пропорцию 1 : 2. Проверь размеры B = 64 и C = 128.
2. Переключись на Flexible. Почему B стал 40, а C остался 128?
3. Измени коэффициент C на 3. Рассчитай доли до проверки в приложении.
4. Переключись на вертикальное направление. Какое измерение теперь делится?
5. В Spacer при коэффициентах 1 : 3 вычисли промежутки. Ответ: 26 и 78.
6. В режиме Flexible попробуй в коде `MainAxisAlignment.spaceBetween`.
   Объясни, куда делись неиспользованные 24.

Для повторения: сначала обычные дети, затем деление остатка по flex;
Expanded заполняет долю, Flexible с loose может занять меньше, Spacer создаёт пустое место.
