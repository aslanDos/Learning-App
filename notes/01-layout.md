# 01. Layout — размеры и расположение виджетов

Ветка: `lesson/01-layout`. Работающий пример: [`lib/main.dart`](../lib/main.dart).

## Что такое Layout

Layout — процесс, во время которого Flutter вычисляет размеры элементов интерфейса
и их положение относительно родителей.

Виджеты образуют дерево. В записи `Padding(child: Text('Привет'))` виджет `Padding`
является родителем, а `Text` — его ребёнком. Один виджет может одновременно быть
ребёнком для внешнего виджета и родителем для внутреннего.

Для базовых примеров удобно говорить «виджет получает размер». Технически расчёты
выполняют объекты рендеринга, которые стоят за виджетами.

## Главное правило

**Ограничения идут вниз. Размеры идут вверх. Положение задаёт родитель.**

Ограничения — допустимые минимальные и максимальные ширина и высота.
Поэтому `width: 80` — запрос размера, который должен укладываться в ограничения.
Подробнее это разберём в теме Constraints.

Размеры задаются в **логических пикселях**: это единицы интерфейса,
которые не обязательно равны физическим пикселям экрана.

## Виджеты первого урока

| Виджет | Задача | Пример |
| --- | --- | --- |
| `SizedBox` | Запросить размер | `SizedBox(width: 80, height: 80)` |
| `Padding` | Оставить отступ между своей границей и ребёнком | `Padding(padding: EdgeInsets.all(16), child: ...)` |
| `Align` | Разместить ребёнка внутри своей области | `Align(alignment: Alignment.topLeft, child: ...)` |
| `Center` | Разместить ребёнка по центру | `Center(child: ...)` |
| `ColoredBox` | Закрасить свою область | `ColoredBox(color: Colors.blue, child: ...)` |

`ColoredBox` помогает увидеть границы примера. Цвет сам по себе не задаёт размер.

`Center(child: ...)` соответствует `Align(alignment: Alignment.center, child: ...)`.

## Пример: квадрат по центру

Этот фрагмент можно поставить вместо `body` у `Scaffold`:

```dart
Center(
  child: SizedBox(
    width: 80,
    height: 80,
    child: ColoredBox(color: Colors.blue),
  ),
)
```

В такой ситуации `Center` занимает доступную область тела экрана,
позволяет ребёнку быть меньше этой области и размещает его посередине.
`SizedBox` задаёт квадрат 80 × 80, если доступного места достаточно.

У `Center` и `Align` нет правила «всегда занимать весь экран».
Их размер зависит от окружения: в нашем примере доступная область ограничена.

## Как читать дерево нашего примера

Декоративные фоны и надпись `child` здесь пропущены:

```text
SizedBox(height: 240)
└── Padding(padding: EdgeInsets.all(16))
    └── Align(alignment: Alignment.center)
        └── SizedBox(width: 80, height: 80)
            └── ColoredBox(...)
```

Читай снаружи внутрь:

1. Внешний `SizedBox` выделяет область высотой 240.
2. `Padding` оставляет по 16 с каждой стороны. Внутренняя высота равна `240 − 16 − 16 = 208`.
3. `Align` располагает ребёнка в оставшейся области.
4. Внутренний `SizedBox` запрашивает размер 80 × 80.
5. `ColoredBox` делает этот квадрат видимым.

Обёртки важны: каждый следующий виджет работает с областью, которую ему оставил родитель.

## Почему отступ иногда не сдвигает блок

При `Alignment.topLeft` блок прижат к верхнему левому углу внутренней области.
Увеличиваем отступ — этот угол смещается вправо и вниз, а вместе с ним и блок.

При `Alignment.center` одинаковые отступы с противоположных сторон уменьшают
область симметрично. Её центр сохраняется, поэтому центр блока остаётся на месте.
Это верно для нашего примера, пока блоку хватает места.

Если отступ только с одной стороны, центр доступной области тоже сместится:

```dart
Padding(
  padding: EdgeInsets.only(left: 40),
  child: Center(
    child: SizedBox(
      width: 80,
      height: 80,
      child: ColoredBox(color: Colors.blue),
    ),
  ),
)
```

## Частые ошибки

- Ожидать, что `width` всегда даст точную ширину. Сначала нужно учитывать ограничения родителя.
- Искать у ребёнка координаты экрана. В обычном layout его размещает родитель.
- Считать `Padding` внешним отступом. Он оставляет пространство внутри собственной области.
- Ожидать заметного эффекта от `Align`, когда его область равна размеру ребёнка: для перемещения нужно свободное место.
- Пытаться исправить расположение случайными обёртками. Сначала посмотри на дерево: кто задаёт размер, отступ и выравнивание?

## Практика

1. В приложении выбери «Слева сверху», поставь отступ 0, затем 40.
2. Повтори с выравниванием «По центру» и объясни разницу.
3. При «Справа снизу» увеличь размер квадрата. В какую сторону он растёт?
4. В коде замени `Align` на `Center`, убрав параметр `alignment`.
5. Замени симметричный отступ на `EdgeInsets.only(left: 40)` и предскажи результат до запуска.

Ответ к заданию 3: при достаточном месте правый нижний угол остаётся на месте,
поэтому квадрат растёт влево и вверх.
