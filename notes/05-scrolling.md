# 05. Scrolling — прокрутка

Ветка: `lesson/05-scrolling`. Пример: [`lib/main.dart`](../lib/main.dart).
Предыдущий урок: [Flex](04-flex.md).

## Зачем нужна прокрутка

Экран или выделенная область может быть меньше содержимого.
Прокрутка позволяет посмотреть разные части содержимого через одно и то же окно.

- **Viewport** — видимая область, окно прокрутки.
- **Content** — содержимое, которое может выходить за размер окна.
- **Scroll offset** — текущее смещение от начала в логических пикселях.
- **maxScrollExtent** — максимальное смещение в обычном направлении прокрутки.

В нашем простом примере без дополнительных отступов:

```text
Viewport: 240
Содержимое: 8 × 72 = 576
Максимальное смещение: 576 − 240 = 336
```

Если элементов только три, их длина 216. Они помещаются в окно 240,
поэтому максимальное смещение равно 0.

## SingleChildScrollView

Принимает одного ребёнка и позволяет прокручивать его по выбранной оси.
Один ребёнок может быть Column с несколькими элементами:

```dart
SizedBox(
  height: 240,
  child: SingleChildScrollView(
    child: Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        SizedBox(height: 160, child: Text('Раздел 1')),
        SizedBox(height: 160, child: Text('Раздел 2')),
      ],
    ),
  ),
)
```

По умолчанию направление вертикальное. Для горизонтального содержимого:

```dart
SingleChildScrollView(
  scrollDirection: Axis.horizontal,
  child: Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      SizedBox(width: 200, child: Text('Часть 1')),
      SizedBox(width: 200, child: Text('Часть 2')),
    ],
  ),
)
```

SingleChildScrollView подходит для небольшой составной страницы или формы,
которой иногда не хватает места. Он не превращает Column в ленивый список:
дети Column создаются сразу. Для длинного повторяющегося списка обычно нужен
ListView.builder — это следующая тема.

## Связь с Constraints и Flex

Окно должно получить конечный размер вдоль оси прокрутки.
Его ребёнок, напротив, получает неограниченный максимум по этой оси,
чтобы содержимое могло оказаться длиннее окна.

Проблемный случай:

```dart
SingleChildScrollView(
  child: Column(
    children: [
      Expanded(child: Text('Заполнить остаток')),
    ],
  ),
)
```

Column не имеет конечного максимума высоты. Expanded требует заполнить долю
оставшегося пространства, но конечную долю здесь вычислить нельзя.
Само по себе `mainAxisSize: MainAxisSize.min` эту проблему Expanded не решает.

Другая структура корректна, если внешняя Column получает конечную высоту,
например является body у Scaffold:

```dart
Column(
  children: [
    Text('Неподвижный заголовок'),
    Expanded(
      child: SingleChildScrollView(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text('Раздел 1'),
            Text('Раздел 2'),
          ],
        ),
      ),
    ),
  ],
)
```

Здесь Expanded задаёт размер **окна**, а не пытается растянуть содержимое внутри него.
В интерактивном примере ту же задачу выполняет SizedBox 240 × 240.

## ScrollController

Контроллер позволяет читать смещение и управлять прокруткой из кода.
Он хранится в State, а не создаётся заново при каждом build:

```dart
final controller = ScrollController();

@override
void dispose() {
  controller.dispose();
  super.dispose();
}
```

Передай его в `SingleChildScrollView(controller: controller, ...)`.
После подключения и расчёта layout можно перейти к концу:

```dart
if (controller.hasClients && controller.position.hasContentDimensions) {
  controller.animateTo(
    controller.position.maxScrollExtent,
    duration: Duration(milliseconds: 350),
    curve: Curves.easeOut,
  );
}
```

- `animateTo(...)` перемещает плавно.
- `jumpTo(...)` меняет позицию сразу.
- `controller.offset` даёт текущее смещение, когда подключена одна область.
- `hasClients` проверяет подключение; размеры содержимого появляются после layout.

Не читай `position` до подключения. Для независимых областей используй
отдельные контроллеры, особенно если читаешь offset или добавляешь интерактивный Scrollbar.
В приложении AnimatedBuilder слушает контроллер и обновляет подпись смещения.

## Scrollbar и physics

Scrollbar показывает, какую часть содержимого мы видим. В примере он получает тот же
controller, что и SingleChildScrollView; `thumbVisibility: true` делает индикатор
постоянно видимым, когда прокрутка возможна.

`physics` задаёт поведение движения:

| Вариант | Поведение |
| --- | --- |
| ClampingScrollPhysics | Останавливается у границ без пружинящего выхода |
| BouncingScrollPhysics | Разрешает пружинящее движение у границ |
| NeverScrollableScrollPhysics | Отключает пользовательскую прокрутку |
| AlwaysScrollableScrollPhysics | Позволяет принимать жесты даже при коротком содержимом |

AlwaysScrollable не увеличивает длину содержимого. Для пружинящего эффекта
на коротком содержимом его можно комбинировать с BouncingScrollPhysics.
В нашем примере явно выбран ClampingScrollPhysics для одинакового поведения на платформах.

## Несколько областей прокрутки

В уроке внешняя страница прокручивается отдельно от демонстрационного квадрата.
Это намеренное разделение: внутренняя область ограничена размером, имеет свой controller
и `primary: false`, поэтому не использует общий PrimaryScrollController страницы.

Вложенные области одного направления требуют аккуратной работы с жестами.
Не рассчитывай, что после достижения конца внутренней области тот же жест автоматически
продолжит прокрутку внешней. В обычном экране часто проще оставить одну основную область.
Для более сложной связанной прокрутки есть другие инструменты; часть из них разберём со Slivers.

## Практика

1. Прокрути вертикальный пример вручную. Следи за смещением.
2. Нажми «В конец». Почему смещение равно 336, а не 576?
3. Нажми «В начало». Проверь, что окно не изменило размер.
4. Переключись на горизонтальное направление и повтори.
5. Отключи длинное содержимое. Почему «В конец» больше ничего не перемещает?
6. В коде измени размер окна с 240 на 200 по оси прокрутки. Рассчитай новый максимум.
   Для 8 элементов ответ: `576 − 200 = 376`.

Для повторения: конечное окно показывает часть содержимого, смещение выбирает эту часть,
а содержимое может быть длиннее окна. Прокрутка не исправляет произвольные ошибки Flex.
